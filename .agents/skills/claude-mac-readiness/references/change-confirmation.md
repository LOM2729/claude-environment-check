# 逐项确认协议

用户要求本 Skill 在每个修改步骤前询问。这个流程适用于每次运行，包括“照教程全改”之类的笼统请求。只读本机检查可直接进行；任何会改变本机或账号状态的操作都要先给出该项具体预览，再等答复。

## 单项预览

每次只提出一个独立变更。使用简短格式：

> 准备修改：设置名称。当前：实际读取值。目标：用户选择值。影响：涉及哪些应用/是否可能断网或重启。回退：恢复原值或备份路径。验证：改后检查什么。请回复“确认修改此项”或“跳过”。

如当前值未知，先只读查清，不能猜测。目标值未定时先问用户选择；用户回答目标值不等于已经确认执行，再呈现该项预览。用户可以一次逐项列出具体批准清单；列表里每项都足够明确时按清单执行，不必对同一项重复问。

## 项目边界

- Mac 时区、Mac 地区、系统语言、Chrome 首选语言、Chrome 应用界面语言各算一项；不要把“改英语”扩展成删除中文或改变整个 Mac。
- Shadowrocket 的“始终开启”“包括所有网络”、DNS、路由配置、代理节点/回退、STUN/WebRTC 各算一项；如果设置会同时改变多个值，在预览中逐一列出。
- 安装或更新软件、清理缓存/登录数据、改 Claude Code 设置、浏览器扩展或权限分别确认；登录凭据、验证码和付款由用户自己在官方界面处理。
- 外部 IP/DNS/WebRTC 检测会向所访问站点发送当前出口等数据。先说明准确站点、目的，以及是否会在本轮修改后同站复测；用户明确同意的范围内不重复问。更换站点、浏览器或数据范围要重新确认。纯本机只读检查不逐项弹问。
- 任何系统权限或管理员密码只由用户在本机提示中输入；绝不要求在聊天里发送。若确认后操作失败，先报告原因，不能把确认范围扩展到新方案。

## 执行后的记录

每项只执行一次，立即读取设置确认生效，再做相应功能测试。记录“已确认并验证”“已确认但未生效”“用户跳过”“未询问未执行”。下一项独立预览；用户明确停止时不再推进。若后续步骤把之前值重置，例如 Mac 地区改变时区，需重新展示修复预览并再次确认。
