# 离线检查面板

Mac 与 Windows 的 `report`、`preflight`、`recheck`、生命周期、恢复及续做报告共用 `scripts/report_dashboard.py`，生成所在输出目录的 `report.html`。保留现有 JSON／Markdown 结果与检查门槛；页面只读取已生成的公开字段，不执行采集、联网、配置或启动。

## 客户看到什么

- 当前必需项默认展开，只有**已完成／未完成**，每项显示原因和下一步；未完成优先。
- 检查时间明确显示时区。普通总报告的顶部标为“检查时间（采集记录）”，逐项真实核验时间在“查看记录”里；页面生成时间放在折叠说明中，不能代替检查时间。
- 后续／补充检查及报告说明默认折叠，不计入本次必需数量；未实测项目保持未完成。
- 页面始终提示这是静态快照。重新打开不会刷新、重新检查或启动软件；需要当前结果时让 Codex 按当前范围重跑检查并生成新目录。

## 使用顺序

继续按 [五步流程](five-step-setup.md) 操作。初期可直接展示简短文字结果，不能为了打开报告提前启动会恢复 AI 标签页的浏览器。网络门槛满足后，客户可在本机打开已生成的 HTML。工具不自动打开浏览器，不注册后台服务、不替换图标或接管既有启动方式。

`preflight` 仍按 [生命周期检查](lifecycle-checks.md) 的本轮记录和授权执行；仅检查时不添加 `--launch`。网页不能提供新的启动许可，旧页面的已完成不代替启动瞬间的检查。报告生成成功只表示展示文件保存成功。

面板没有 JavaScript、CDN、外部字体、表单或遥测，只用本地 CSS 和原生折叠控件；Tab 定位，Enter／空格展开。桌面和窄窗口均显示文字状态，颜色不作为唯一标识。详细私有证据、凭据、原始配置和IP不传给展示层；上游公开原因及下一步仍须先脱敏。

## 实现与验证

界面结构参考 Claude-Guardian 固定版本 `893a58d3a7b792fd6fde823b7d560be5cd5663e0` 的 [离线面板说明](https://github.com/DUNHKpcc/Claude-Guardian/blob/893a58d3a7b792fd6fde823b7d560be5cd5663e0/docs/environment-dashboard.md)：简洁表格、记录折叠、静态快照。本包独立实现展示代码，连接自己的二状态报告，没有复制其源码或导入其报告格式。

单元测试覆盖状态、时间、计数、转义、私有字段和无副作用；浏览器预览只使用合成材料，检查桌面／窄屏、键盘展开与溢出，不代表客户网络或客户端已经验收。面板不改变实际代理规则、DNS、UDP／IPv6或启动行为。
