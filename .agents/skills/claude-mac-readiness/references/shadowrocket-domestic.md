# 小火箭原生国内视频与 UDP 配置

与 Clash 使用同一份 AI/视频/国内域名快照和相同策略顺序。`ai-route --policy domestic-v4 --format shadowrocket` 自动生成完整 `candidate.conf`，展开为原生 DOMAIN/DOMAIN-SUFFIX 规则，不包含 Mihomo inline provider，不让客户手工粘贴名单或编辑 JSON。配置生成可在 Mac/Windows 上运行；小火箭实际应用验收只在支持的 Apple 设备上进行，Windows 生成文件不等于 Apple 设备已配置。

## Codex 完成操作，客户只处理必要交接

1. 识别真正运行小火箭的设备与版本，读取当前活动 `.conf`、配置模式、指定节点、DNS及应用开关。节点仅存首页/订阅时，由 Codex 使用本机受支持的导出/分享入口把选定具体节点物化到私有配置的 `[Proxy]`；保留必要其他节点和组引用。不把默认 `PROXY`、未知订阅或选择器冒充具体节点，不上传凭据到第三方转换站。
2. 先运行 `udp-check`，核对小火箭设置中的 **UDP 转发**：本机应用自带说明提示，关闭时可能全部直接转发 UDP，不能把关闭它当作禁 UDP。让 UDP 进入配置规则判断；如现有设置冲突，列入具体方案。保留节点层限制，核对 `udp-policy-not-supported-behaviour = REJECT`。全局 QUIC 阻断、系统网络过滤器和应用扩展也可能先于视频规则生效，按准确范围处理，不批量放开所有 UDP。
3. Codex 准备完整备份、DIRECT 分类、候选及差异，按一次批准范围执行。转换保持顺序：AI UDP 拒绝与指定代理保护 → IPv6 拒绝及既有非 AI 拒绝 → 国内视频直连 → 其余 UDP 拒绝 → 国内域名直连 → 原已审阅规则及统一代理兜底。遇到企业拒绝、代理例外与名单冲突时先处理具体冲突，不能静默覆盖。
4. 在当前版本“配置 → 导入…”选择生成的本地 `.conf`，使用独立可识别名称；导入不等于选中或启用。先检查候选的脚本、外部资源和编译是否联网，确认后由 Codex 执行当前软件提供的编译/检查。禁止为测试直接切换正在承载 Codex 的代理。能通过界面完成的导入、规则检查和导出由 Codex 完成；确实缺设备控制权限时只交接最少点击，不让客户转换格式或配置技术参数。
5. 活动配置切换、重载或开关若可能断开控制通道，按 [客户手动重启与恢复](five-step-setup.md#客户手动重启与恢复) 保存进度与离线恢复材料，由客户在准备好后执行。没有该风险且已有具体批准的操作由 Codex 连续完成。小火箭“全局路由”应按配置执行，不能只检查 VPN 开关。
6. 从实际导入/活动配置导出或读回完整内容，`verify` 核对计划，`ai-audit --policy domestic-v4 --format shadowrocket` 核对顺序、全量名单、指定节点、IPv6和UDP回退。客户只需选择节点、批准方案、处理系统认证及必要重启。新配置/订阅更新后重复读回，不修改软件私有数据库冒充受支持导入。
7. 按原五步顺序先验证 DNS、代理、IPv6和非 AI 路径，再生成新 dns-ready，再进行 AI 服务测试。小火箭规则测试页通常只显示域名命中，不能单独证明 UDP 数据包行为；需要实际 UDP 接管、国内视频/CDN命中、其余 UDP 拦截和 TCP 出口证据。故意断代理测试须有独立授权和恢复通道。iPhone/iPad 不能拿 Mac/Windows 的网络采集当成该设备证据。

## 原生格式与来源

- DOMAIN-SUFFIX/DOMAIN 由同一固定快照转换，视频白名单的范围不扩大；普通国内域名位于其余 UDP 拒绝后。
- 小火箭的 `PROTOCOL` 使用在 AND 逻辑子规则中。全 UDP 拒绝使用 `AND,((PROTOCOL,UDP),(PROTOCOL,UDP)),REJECT-NO-DROP`，两个相同条件表达“UDP且UDP”，避免猜测独立 PROTOCOL 或端口范围语法。
- IPv6 拒绝采用小火箭 `IP-CIDR,::/0,REJECT,no-resolve`，不写 Mihomo 的 IP-CIDR6。保留 `ipv6 = false`，系统层关闭与远端出口另验。
- 软件一方资料：本机 Shadowrocket 2.2.92（3445）应用包内 `default.conf` 展示 AND + PROTOCOL UDP、IPv6 IP-CIDR 和 `udp-policy-not-supported-behaviour = REJECT`；应用自带界面说明解释 UDP 转发开关。这里只记录最小语法事实，不再分发应用源码/完整默认配置。
- [社区说明](https://github.com/LOWERTOP/Shadowrocket/wiki) 用于补充操作入口与 PROTOCOL 子规则限制，不标成厂商官方。具体版本接受与实际流量行为以本机编译、读回和运行验收为准。

## 测试与报告边界

离线测试覆盖全量域名展开、与 Clash 快照一致、旧规则迁移、重复生成、注释保留、精确节点和回退策略、损坏管理块、篡改检测、CLI `.conf` 输出与不泄露凭据。Mihomo 核心测试不等于小火箭核心测试。

本地静态生成/读回、原生导入/编译、实际 UDP/TCP 路径分别记录；只有对应证据才标已完成。无法自动控制某个客户端入口时说明具体原因和最少下一步，不直接把整份配置任务交还客户。报告仍只有已完成/未完成，不打分。

本轮原生验证：macOS 上 Shadowrocket 2.2.92（3445）已成功导入合成的完整配置，识别 110554 条规则，编译显示成功；原生导出 .conf 与候选语义完全一致。测试节点只指向 loopback，未启用测试配置，未切换既有代理，测试后已清理导入副本与附带节点组。实际 UDP/TCP 转发、视频播放和 iOS/iPadOS 版本仍须目标机验收。
