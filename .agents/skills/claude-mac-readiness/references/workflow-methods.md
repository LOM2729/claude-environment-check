# 专题入口（按任务读取）

首次／完整配置只按 [五步流程](five-step-setup.md)；下表用于局部任务，不另设一套操作顺序。纯资料任务只读写相关文件，不采集设备、探测网络或执行清理。新增专题也不自动扩大原任务。

| 任务 | 读取入口 | 范围 |
| --- | --- | --- |
| 连不上、认证或客户端差异 | 对应平台检查参考；[事故分流](incident-and-cleanup.md) | 从实际故障入口开始，不因错误码直接清缓存或换 IP |
| 浏览器体检或客户自助回报 | [自助问题卡](score-check.md#客户自助回报) | 仅在已批准范围收红黄项，用户转述不直接变成系统验收 |
| 浏览器定向清理 | [浏览器清理](browser-cleanup.md) | 精确 Profile／站点／数据类别，默认仅可再生缓存 |
| 客户端清理、重认证、卸载 | [客户端清理](client-cleanup.md) | 区分缓存、登录、历史、配置、程序及云端操作 |
| 代理导入、IPv6／DNS／UDP | [配置导入](proxy-import.md)、[统一出口](unified-ipv4.md)、[业务与UDP](domestic-video-udp.md) | 只读相关问题；更改网络时沿五步的准备、应用和核验要求 |
| 后台、MCP、WSL或远端路径 | [执行位置](execution-paths.md) | 每个实际进程／执行端分别验证 |
| 中断续接、恢复、更新或事件复查 | [进度](workflow-progress.md)、[恢复](recovery-and-acceptance.md)、[生命周期](lifecycle-checks.md) | 只读当前需要的一份；部分写入先对账，不覆盖后改 |
| 本机／VM／VPS路线 | [路线规划](deployment-routes.md) | 分清执行机、中转和公网出口，涉及管理修改先备独立救援 |
| 注册订阅、账单或当前限制 | [账号准备](account-preparation.md)、[账单](billing-checks.md)、[事故分流](incident-and-cleanup.md) | 仅展开当前问题，已有账号不重注册；登录／支付由本人完成 |
| 数据隔离、原生规则、系统防护、远端部署或专项检测 | [可选执行工具](execution-capabilities.md) | 先核本轮平台／能力与具体计划，未验收不报效果通过 |
| 身份迁移或完整来源比较 | [研究索引](source-index.md) | 跨机身份迁移仍为来源方法，不把隔离备份当迁移执行器，未验证方法不默认执行 |

离线核对清理对象、隔离和保留项无需重配网络；需要启动、登录、更新或外部请求时，再满足五步中的网络前置条件。删除与本地备份恢复、服务端撤销／云端删除分别判断，不能承诺全部可撤销。
