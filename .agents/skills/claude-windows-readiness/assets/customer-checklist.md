**使用方式：先记录现状 → 准备具体差异 → 按所选模式确认 → 执行已批准项 → 复测 → 交接。** 勾选表示已处理并有结果，不等于全部通过；不适用或未测要写原因。完整服务各项先检查，设置不默认全改。

| 项目 | 在哪里、怎么处理 | 完成标志 |
| --- | --- | --- |
| □ 01 目标与恢复 | 确认客户电脑、实际用户、原生／WSL／VM 执行位置；远控时准备独立恢复办法 | 本机与客户机、Windows 与 WSL 不混用证据 |
| □ 02 时间与时区 | 设置 → 时间和语言 → 日期和时间；需要手选时区才关闭自动时区，通常保留自动设置时间；用 `Get-TimeZone` 读回 | 时间准确，时区 ID 和自动选项符合目标 |
| □ 03 系统语言／区域 | 设置 → 时间和语言 → 语言和区域（Win10 为相应独立页面）；分别看显示语言、区域格式、国家／地区和输入法 | 只改约定项，日期格式与常用软件正常 |
| □ 04 浏览器语言 | Chrome／Edge → 设置 → 语言，调整网页首选语言；需要菜单英语时另选显示语言并重启 | 菜单与网页语言分别核对，保留所需中文和输入法 |
| □ 05 浏览器档案 | 核对实际 Profile、代理扩展、受管理政策；按工作需求选择独立档案，不删除旧档案 | 检测和日常使用在同一档案；企业政策未被覆盖 |
| □ 06 文件与备份 | 识别完整 YAML、规则扩展、节点订阅；小火箭 conf 不能改名作 YAML；备份活动配置和开关 | 原件、备份可读；候选差异及目标核心兼容性明确 |
| □ 07 Clash 导入 | Clash Verge Rev 的订阅／配置 → 新建本地／选择文件，或支持的拖拽；规则片段用对应扩展入口 | profile 被选中、核心无加载错误，旧配置仍可选回 |
| □ 08 代理与 TUN | 核对组内节点、Rule／Global／Direct、系统代理／PAC、TUN／服务模式、实际监听端口 | 系统设置与客户端生效配置一致；提权由客户在本机处理 |
| □ 09 规则与分流 | 检查 Claude 功能域名、进程与共享运行时、组引用、前置规则、兜底、自动切换及 DIRECT 回退 | 真实请求命中预期出站；国内、LAN、企业 VPN、远控按约定可用 |
| □ 10 DNS／安全 DNS | 设置 → 网络和 Internet → 实际适配器的 DNS 设置；结合 `Get-DnsClientServerAddress`、核心 DNS 和浏览器安全 DNS | 系统、核心、浏览器及节点解析分别有记录，无引导循环 |
| □ 11 TYPE64／65 | 分别检查 SVCB／HTTPS 的处理；先核实解析工具支持，不把 DNS64 与 TYPE64 混淆 | 保留成功／无答案／不支持／超时，过滤效果有对照才下结论 |
| □ 12 IPv4／IPv6 | 用实际接口与路由信息检查；区分 DNS AAAA、系统 IPv6、节点外层和目标侧；不默认解绑网卡 IPv6 | 双地址族及例外覆盖明确；未测部分不写通过 |
| □ 13 WebRTC／UDP | 在实际浏览器 Profile 中做已批准检测；检查策略、STUN、QUIC、UDP 回退和媒体需求 | 候选与同地址族出口核对，失败为受限；媒体功能复测 |
| □ 14 网页／Desktop | 分别检查打开、登录、已有会话最小任务；按用途检查附件／Artifacts／组件 | 真实功能可用，状态码错误按来源分诊 |
| □ 15 Claude Code | 原生终端核对命令、版本、认证和代理来源；变量检查脚本只输出键名状态 | 真实 CLI 请求可用；不是用浏览器成功替代 |
| □ 16 WSL／远端 | 仅使用时检查实际发行版／远端内的 DNS、代理、认证和进程；不要假定 Windows 回环端口天然可达 | 各执行环境单独实测；未使用可注明不适用 |
| □ 17 持久化／故障 | 设置 → 应用 → 启动及代理自身开关；核对服务、配置扩展。获准后测试 GUI／核心退出、换网／睡眠等 | 区分静态检查和演练；恢复后网络、内网及远控正常 |
| □ 18 交接 | 交付变更、版本／配置标识、逐客户端结果、未测项及离线恢复步骤 | 客户能使用和恢复，知道更新后需要复验哪些项 |

**每次改动记录：** 项目___　原值___ → 新值___　批准范围___　备份／回退___　读回___　功能复测___。

**每项结果：** □ 已完成　□ 未完成。未完成原因：___；下一步：___。修改前按所选模式取得具体批准；客户暂不修复仍存在的问题保持未完成。客户确认无关的项目不计入总数并记录范围原因。

**证据标签：** 官方／标准、第三方源码、个人经验／社区资料、用户提供、静态配置、模拟测试、目标机实测。配置声明、应用载入、进程采用和端到端观察分别记录；检测分数不等于账号安全结论。
