## 原始观察与验证依据

记录实际设备／客户端／档案、版本、时间、配置修订及观察范围。官方文档、个人经验、静态配置、模拟测试和目标机实测分开。配置写入、应用载入、进程采用、端到端观察分别记录，但不作为新的报告状态。

故障实验仅记录实际完成的获准场景、预期、观察及恢复；检测失败或网站打不开不能证明无直连。没有实测的项目保持未完成，写清原因和下一步。
