# Windows 逐项确认协议

用户要求每个修改步骤前确认。本协议在每次运行中生效：先只读观察，再向用户逐项预览。不要把“全部帮我配置”解释成对所有具体变更的预先批准。

## 单项预览格式

> 准备修改：设置名称。当前：实际读到的值。目标：用户选定值。影响：哪些程序、是否要重启或可能断网。回退：原值或备份位置。验证：修改后如何确认。请确认此项或回复“跳过”。

目标不明确时先问目标值；得到目标后再展示预览。若用户已经逐项列明并批准同一具体修改，不重复询问。一次只处理一项；确认只覆盖所述范围，不外推到后续项。

## 项目拆分

- Windows 时区、国家或地区、区域格式、Windows 显示语言、Chrome 首选语言、Chrome 界面语言各算一项。只要求 Chrome 英语时，不改 Windows 显示语言。
- 代理软件的 TUN、DNS、IPv6、最终路由、失败回退、自动连接、开机启动、防火墙规则各算一项。若软件界面把多个值绑定成一次操作，预览列出所有变化。
- 清缓存、退出登录、卸载软件、删除配置、改 Claude Code 变量、浏览器权限分别确认。真实付款、验证码和系统管理员凭据只由用户在本机官方界面处理。
- 外部检测站访问前告知准确域名、会传出的当前出口信息，以及是否会在本轮修改后同站复测；用户明确同意的范围内不重复问。更换站点、浏览器或数据范围时重新确认。本机只读 PowerShell 查询不用逐个弹问。

## 结果记录

每项标记为“已确认并验证”“已确认但未生效”“用户跳过”或“未询问未执行”。修改失败后先报告原因；新方案需新的预览。网络故障模拟与日常设置修改是独立操作，必须另行确认。用户叫停后立即停止后续步骤。
