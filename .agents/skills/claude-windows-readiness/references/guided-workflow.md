# X 帖八章引导流程

自动配置顺序以 [五步流程](five-step-setup.md) 为准。网络及选定接口 IPv6 未核验前，不打开/安装/登录 AI，不运行未证明离线的 CLI 诊断，不重启浏览器恢复标签。代理校验/导入/启用/重载前先检查测速、health-check、资源下载及附加请求。纯本机时间/语言字段检查可并行。

适用于用户明确要求完整走一遍[原始 X 长文](https://x.com/suyuan1711/status/2102744129235193975)的主题。先一次性确认系统、现有账号阶段、实际使用的浏览器和代理软件、希望检查的范围；可并行完成不涉及账号内容的本机只读检查，不必每章停下来询问。随后按八章顺序报告观察与跳过理由，集中列出候选修改，再按单项确认协议逐项执行。把“已检查”“经授权修改并复测”“用户自行完成”“不适用/跳过”“未验证”分别记录。原帖是个人经验，不是 Anthropic 官方配置清单，也不提供保号保证。

| 原帖主题 | 本 Skill 要完成的核对 | 动作边界与阶段结果 |
| --- | --- | --- |
| 一、账号与封禁说法 | 查当期 Anthropic 支持地区、账号实际使用地点和官方使用规则；分开看政策风险、网络故障与内容/工具使用问题。 | 不把“账号权重”“注册头几天决定命运”当作已证实机制。若地点不受支持，先说明政策限制，不能把更换出口或时区包装为合规方案。 |
| 二、注册时的网络出口 | 只读核对当前代理类型、出口地区/ASN、切换频率和稳定性；询问是否已有账号，已有则不重新注册。 | 不要求购买静态住宅 IP，不推荐节点商家；出口检测要告知目标站点和会传出的 IP 并先确认。输出网络事实，不推断会否通过账号审核。 |
| 三、浏览器与邮箱 | 在用户实际使用的浏览器里核对语言列表、Intl 区域/时区、WebRTC、地理位置权限及登录链接打开位置；只看邮箱的远程图片/跟踪链接隐私设置，不读收件箱或邮件正文。 | 不自动安装指纹浏览器、随机化设备身份、改字体或强迫换邮箱。新账号、邮箱链接与同意条款由用户本人在官方界面处理。Gmail 图片代理与 Proton 跟踪防护要区别说明。 |
| 四、本机状态 | 只读核对 Windows 时区、国家/地区与区域格式、Chrome 界面/首选语言、Claude Desktop/Code 安装和历史登录数据。 | 时区、地区、语言、清理旧数据各自单项确认；清理前盘点与备份。不得因“分数”而删除系统字体、轮换设备 ID 或抹掉其他项目数据。 |
| 五、分流与断线 | 找到当前生效的代理配置，核对 DNS、浏览器和终端实际路径；分别检查节点坏、隧道消失、休眠/换网，记录回退到 DIRECT 的可能性。 | 每项网络改动先备份与确认。故障演练可能断网，需独立授权和恢复路径；静态检查不能代替实测。按 [第三方分数检测](score-check.md) 可选做基线和复测。 |
| 六、订阅 | 只读核对用户愿意展示的当前计划及官方公开的当期方案，说明订阅与 API 是不同产品；没有订阅目标时不进入结账页。 | 付款、账单资料、验证码和任何 KYC 由用户本人处理；不虚构地址、不代购账号、不承诺退款或付款通过。只记录用户确认的结果，不读取支付信息。 |
| 七、Claude Code | 从官方来源核对安装方式、版本、PATH、doctor 与 CLI 登录状态；再验证 CLI 所用路径，避免把 Desktop 已登录当作 Code 已登录。 | 安装软件前单项确认；OAuth 登录由用户本人完成。旧 API key 或 BASE_URL 可能改走其他路径，只报告键名/来源，不输出值。 |
| 八、套餐升级与续费 | 若用户需要，查看官方当前方案、扣费/续费状态和可用功能。 | 不把“先聊几次”“隔一天升级”等原帖经验变成必做门槛；升级和续费属于用户本人付款决定。价格和计划变动以当期官方页面为准。 |

若客户已经使用比特浏览器等独立浏览器配置，只读核对其下载来源、当前配置文件对应的代理、语言、时区、WebRTC 与地理位置权限；不能仅因配置页写着“禁止泄露”就断言断线安全。需要故意断开代理验证时，另行说明可能失联并取得该项确认。

## 修改顺序与停手条件

先处理可证实的实际泄露或连接故障，再处理用户明确要求的体验设置；语言、字体、Emoji 等评分提示不单独构成系统修改理由。若账号实际使用地点不在官方支持范围，停止把注册、订阅或伪装地区当成“配置修复”，可继续完成用户需要的一般设备/网络诊断并如实报告政策限制。若代理不稳定、备份失败或远程恢复路径不明，暂不做会让设备断网的修改。

## 每阶段收尾

用一行记录：阶段名、观察到的事实、用户确认的动作、实际验证、跳过或阻塞原因。每项修改按 [逐项确认协议](change-confirmation.md)预览；用户已明确批准的同一具体项或清单可以跨阶段复用，阶段切换本身不使授权失效。新增目标、扩大影响或改用另一方案须重新预览。结束时按 [报告模板](../assets/report-template.md)汇总八章状态，不把第三方分数写成 Anthropic 风控结论。

客户最终报告统一只显示“已完成／未完成”。上文的已检查、跳过、未验证等仅作为过程说明或未完成原因，不作为额外状态；客户确认无关的项目不计入总数。每项修改前按确认协议询问客户是否需要调整，未获明确答复不执行。
