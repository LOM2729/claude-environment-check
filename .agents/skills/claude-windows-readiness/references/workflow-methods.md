# 专题入口（按任务读取）

首次／完整配置只按 [五步流程](five-step-setup.md)；下表用于局部任务，不另设一套操作顺序。纯资料任务只读写相关文件，不采集设备、探测网络或执行清理。新增专题也不自动扩大原任务。

## 单入口向导

用户只需给出本仓库地址和目标，Codex 复用已有信息，先用普通语言确认尚不清楚的账号／订阅阶段、目标系统、希望解决的问题与已有网络资源。能从当前材料确定的事实直接沿用，技术字段和模块选择由 Codex 准备。

```text
请使用 https://github.com/LOM2729/claude-environment-check 当前 main 的对应平台 Skill，按我的实际情况带我一步步准备和使用 Claude。根据需要配置环境、开通或升级，或处理故障、申诉退款。复用已有信息，技术方案由你准备，按授权执行并核验，认证和付款由我完成，最后简报结果。
```

| 用户当前情况或选择 | Codex 衔接的本轮路线 |
| --- | --- |
| 首次了解或尚无账号 | 先确定真实用途、当前支持条件和已有资源，给可选路线与成本，用户选定后准备相应环境；注册与认证在官方入口由本人完成 |
| 已有账号，尚未订阅 | 复用当前账号与环境，按需要完成网络准备，再比较真实可用渠道和当前套餐，带到本人购买及权益核对 |
| 已有可用付费账号 | 直接处理所需环境配置、故障或更新，保护仍有效的账号、出口和工作资料 |
| 只需要环境配置 | 按 [五步流程](five-step-setup.md) 准备、确认、应用、核验和交付，完整方案纳入支持的海外分类与日更 |
| 准备升级、续费或已扣未开通 | 读取 [账号准备](account-preparation.md) 与 [账单](billing-checks.md)，核原渠道、当前订单、权益和恢复购买，避免重复购买 |
| 账号受限、想申诉或退款 | 先按 [事故](incident-and-cleanup.md) 核实际通知和目标，再准备真实申诉或 [原渠道退款与复议](billing-checks.md)；用户可选择当前要处理的分支 |
| 只需要清理、比较方案或看资料 | 进入下表对应专题，按明确数据范围或说明目标完成，保留其余事实和后续选项 |

每个分支先给本轮简短路线、需要用户选择的关键点和准确影响，已有具体批准的范围连续推进。用户名、密码、token、支付和身份资料分别在本人受控位置处理，客户无需填写技术 JSON。讨论注册或付款方式时按当前官方条件说明，实际启动／登录遵守五步中的网络前置核验。

用户完成手动步骤后，Codex 接着核对当前结果与下一步。明确区分环境配置、账号本人确认、订阅实际生效和客户端真实功能，按需要保存私有进度继续。完成用户当前目标后交付已完成、未完成原因与下一步，其他分支由用户按需要选择。

## 局部任务

| 任务 | 读取入口 | 范围 |
| --- | --- | --- |
| 连不上、认证或客户端差异 | 对应平台检查参考；[事故分流](incident-and-cleanup.md) | 从实际故障入口开始，不因错误码直接清缓存或换 IP |
| 浏览器体检或客户自助回报 | [自助问题卡](score-check.md#客户自助回报) | 仅在已批准范围收红黄项，用户转述不直接变成系统验收 |
| 浏览器定向清理 | [浏览器清理](browser-cleanup.md) | 精确 Profile／站点／数据类别，默认仅可再生缓存 |
| 客户端清理、重认证、卸载 | [客户端清理](client-cleanup.md) | 区分缓存、登录、历史、配置、程序及云端操作 |
| 代理导入、海外分类、名单更新、IPv6／DNS／UDP | [配置导入与日更](proxy-import.md)、[统一出口](unified-ipv4.md)、[业务与UDP](domestic-video-udp.md) | 按本轮范围准备来源、规则、缓存与恢复，更改网络沿五步执行并核对实际结果 |
| 后台、MCP、WSL或远端路径 | [执行位置](execution-paths.md) | 每个实际进程／执行端分别验证 |
| 中断续接、恢复、更新或事件复查 | [进度](workflow-progress.md)、[恢复](recovery-and-acceptance.md)、[生命周期](lifecycle-checks.md) | 只读当前需要的一份；部分写入先对账，不覆盖后改 |
| 本机／VM／VPS路线 | [路线规划](deployment-routes.md) | 分清执行机、中转和公网出口，涉及管理修改先备独立救援 |
| 注册订阅、账单或当前限制 | [账号准备](account-preparation.md)、[账单](billing-checks.md)、[事故分流](incident-and-cleanup.md) | 仅展开当前问题，已有账号不重注册；登录／支付由本人完成 |
| 数据隔离、原生规则、系统防护、远端部署或专项检测 | [可选执行工具](execution-capabilities.md) | 先核本轮平台／能力与具体计划，未验收不报效果通过 |
| 身份迁移或完整来源比较 | [研究索引](source-index.md) | 跨机身份迁移仍为来源方法，不把隔离备份当迁移执行器，未验证方法不默认执行 |
| 明确要求按夙愿 X 教程核对 | [九章新版与八章历史主题](guided-workflow.md) | 按本轮阶段取相关方法，来源参数、当前工具能力和目标验证分别记录 |

离线核对清理对象、隔离和保留项无需重配网络；需要启动、登录、更新或外部请求时，再满足五步中的网络前置条件。删除与本地备份恢复、服务端撤销／云端删除分别判断，不能承诺全部可撤销。
