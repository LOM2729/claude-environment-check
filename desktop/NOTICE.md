# Desktop dependencies

The desktop interface and workflow integration are independently implemented for this repository. CCBaga is a product-interaction reference; its code, branding, browser and vendored UI have not been copied.

Electron is distributed under MIT with Chromium and other third-party notices included in the runtime distribution. Retain Electron's LICENSE and LICENSES.chromium.html when redistributing the app.

The embedded engine uses Python (Python Software Foundation License), PyYAML (MIT) and the PyInstaller bootloader (GPL with the bootloader exception). Their upstream notices and license texts are included in the legal directory where available. The existing domestic rule data notices remain inside the portable kit and embedded source resources.
