# 轻量配置工具：需求与实现范围

状态：独立窗口已实现；Mac 原生载入／另存与文件读回已验证，Windows 构建验证进行中。

- 客户自助操作，交付人员接手异常；安装包体积和操作步骤都要精简。
- 延续 Mac／Windows。独立原生窗口，不把主体界面放进浏览器，不附带 Electron／Chromium。
- 自动识别已有 Clash／Mihomo 配置；有多个来源时选择，资料不完整或无法确认时选择导出文件。不用 mtime 猜活动配置。
- 沿用客户具体节点或完整标准 dialer-proxy 链，不自动拆链、补造凭据或替换出口。暂不支持/不完整的链路明确报缺口。
- 用客户现有浏览器打开 Net.Coffee 的 IP、DNS、WebRTC 页面，客户人工检测并记录；不自动抓取站点结果，不把打开网页当成通过。
- 预览、静态审计并另存独立 YAML；原文件不覆盖。客户手动导入、启用、复测。
- 系统 DNS、浏览器 WebRTC、IPv6 等只给指引，不自动修改。不停止、重载、切换或重启现用代理，不创建自启或常驻守卫。
- 配置、节点凭据、私有差异及恢复记录仅保存在本机；异常摘要仅复制脱敏计数和固定错误码。

验收重点：源文件和链路定义保留、引用完整、候选可重新解析且静态审计一致、不覆盖任何已有输出、缺口可解释、无自动运行态操作；Mac／Windows 分别构建与冻结引擎自检。窗口点按和真实客户端验收分别记录，合成测试不能代证。

实现说明：复用已有 Python 引擎，使用系统窗口组件；构建中实测包体积及耗时。旧 Electron 产品及其他会话未完成界面修改保留，不整树覆盖。
