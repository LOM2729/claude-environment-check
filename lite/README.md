# Clash 配置助手 Lite

独立原生小窗口，复用现有 Python 配置引擎，不包含 Electron／Chromium，不调用大模型 API，客户不需要打开 Codex。支持 Mac 与 Windows；打包版自带运行时，客户无需安装 Python。仅处理客户本机配置，不修改当前客户端或网络。

## 客户操作

1. 打开应用，自动查找 Clash/Mihomo 配置。无法确认时选择客户端导出的完整 YAML/JSON；选择记录不等于运行核心已采用。
2. 核对出口节点／代理链。可选地从配置中明确声明的 loopback 控制接口只读获取版本和选择；接口不可用时手动选择，不要求客户开放接口或关闭认证。
3. 点击 IP／DNS／WebRTC 按钮，在平常使用的浏览器中打开 Net.Coffee 页面并手动检测、记录结果。程序不会读取检测页结果，也不把打开网页或人工记录当成自动检测通过。
4. 核对窗口内简短变更说明：副本将 AI 与普通国外访问统一至所选出口、追加国内直连及 UDP 规则，候选关闭 IPv6；原有 DNS 上游沿用。生成并另存独立 YAML，原文件不覆盖。客户自行导入、选择启用并复测。文件内容核对不代表 DNS／出口或实际 AI 功能通过。

## 第一版能力边界

- 支持标准完整 Mihomo YAML/JSON、具体本地节点和完整 `dialer-proxy` 依赖；原节点定义、代理链、原组成员和凭据字段保留。
- 旧式 relay、循环依赖、未取得具体节点的提供器链、未知本地文件资源等显示缺口，交由服务人员处理；不会自动拆链、猜凭据或改用可读到的中转节点。
- 地理库、原有远程规则等依赖保留并注明未核验，需要沿用原客户端和资源，不能宣称完全独立、可跨设备部署或已通过运行验收。
- 不自动改系统 DNS、IPv6、TUN、浏览器、系统语言或时区，不自动导入、切换、重启代理，不触发测速/healthcheck/订阅刷新。
- 原配置、副本、私有差异和导出记录留本机私有工作目录。生成文件可能包含节点凭据，请勿发到公开聊天。
- 本版未做商业签名／公证，不要求关闭系统安全策略。原生窗口可用性、真实客户端和真实设备网络分别验证。

## 开发与验证

开发使用 Python 3.12+（含 Tcl/Tk）和 PyYAML 6.0.3。构建依赖安装到任务虚拟环境，不改系统 Python。

```sh
python -m lite.app
python -m lite.app --config /path/to/synthetic.json --no-auto
python -m lite.app --self-test
python -m unittest discover -s tests -p 'test_lite_*.py' -v
python lite/build.py
```

`--no-auto` 禁止发现真实客户端或读取本地控制接口，供合成 UI 验证。`--self-test` 只在临时目录生成和核对合成链式配置，并加载 Tcl；不会启动窗口、联网或操作真实客户端。打包后重复该检查；Windows windowed 引擎用 `--result <新文件>` 输出记录。

Mac／Windows 分别原生构建，产物与大小、哈希及自检记录在 `lite/release/`。实际包体积以构建结果为准。旧版 Electron 桌面源码及交付包保留，不整树覆盖其他未完成界面改动。
