# Clash 配置助手 Lite

独立原生小窗口，复用现有 Python 配置引擎，不包含 Electron／Chromium，不调用大模型 API，客户不需要打开 Codex。支持 Mac 与 Windows；打包版自带运行时，客户无需安装 Python。仅处理客户本机配置，不修改当前客户端或网络。

## 规则热更新（0.2.0）

- App 启动及保持打开期间每 30 分钟，在后台访问本仓库的 `lite-rules` 数据发布通道；不阻塞选配置或生成。可取消窗口内“自动更新”，也可手动检查。GitHub 会看到连接出口 IP，配置、节点、订阅及凭据不上传。
- 仅接受五种固定数据文件：AI 域名目录、国内域名、国内视频域名、国内来源/校验信息、社区域名与 IP/ASN 快照。压缩包约 0.5 MB，以实际构建为准。下载校验 SHA-256、格式、兼容版本和核心目标后，保存本机私有缓存。
- 每次生成固定使用一个不可变的规则快照，并在私有审计和导出记录中写入版本。更新不改已生成/已导入的 YAML，不切换、重载或重启代理；新的副本仍需客户自行导入和复测。
- 无网络、尚未发布通道、校验失败或不兼容时，继续使用上次校验成功的缓存；没有缓存时使用内置规则。缓存损坏时可退回上一份有效缓存。远端降低版本或同版本换内容会被拒绝。
- 不下载或执行 Python、Shell、Skill Markdown 或其他程序。Skill 中的流程、算法、硬编码策略/扩展关键词和新数据格式仍需升级 App；规则数据更新无需换 App。

发布端：主分支 `Cross-platform verification` 成功后，`Lite rules channel` 构建并发布经过验证的数据文件，保留主程序的 latest Release。手动发布也只接受已通过验证的当前 main。测试分支只构建预览数据，不自动公开通道。首次合并/启用发布通道需要仓库维护者授权。

已缓存或导出的配置后续审计应使用记录中对应版本的规则；不能用“当前最新”规则代证旧文件已验证。

## 客户操作

1. **读取配置**：自动查找 Clash/Mihomo 配置，找不到时通过右下角主按钮选择导出的完整 YAML/JSON。核对预选节点，含中转时明确提示完整保留。选择记录不等于运行核心已采用。
2. **核对网络**：分别打开 IP／DNS／WebRTC 的 Net.Coffee 页面，人工选择“未见异常”或“需要协助”；不确定时交给交付人员，不要求客户自行诊断技术原因。程序不会读取网页结果，不把请求协助或打开页面当成检测通过。更换文件/节点会清除旧的人工记录。
3. **生成副本**：先显示出口、保留范围和未检查/需协助项目，再另存全新 YAML。具体 UDP、IPv6、DNS 调整放在“查看具体调整”，技术更新状态和脱敏摘要放在“帮助”；保存快捷键也先显示确认页。
4. **保存成功**：直接显示 Clash 导入、手动启用和复测的下一步。当前客户端不会被自动操作。文件内容核对不代表 DNS／出口或实际 AI 功能通过。

副本将 AI 与普通国外访问统一至所选出口、追加国内直连及 UDP 规则，候选关闭 IPv6；原有 DNS 上游沿用。规则后台检查失败不占用配置任务。文件读取等待较久时会提示检查系统访问询问及本机目录，不自动修改系统权限。

## 第一版能力边界

- 支持标准完整 Mihomo YAML/JSON、具体本地节点和完整 `dialer-proxy` 依赖；原节点定义、代理链、原组成员和凭据字段保留。
- 旧式 relay、循环依赖、未取得具体节点的提供器链、未知本地文件资源等显示缺口，交由服务人员处理；不会自动拆链、猜凭据或改用可读到的中转节点。
- 地理库、原有远程规则等依赖保留并注明未核验，需要沿用原客户端和资源，不能宣称完全独立、可跨设备部署或已通过运行验收。
- 不自动改系统 DNS、IPv6、TUN、浏览器、系统语言或时区，不自动导入、切换、重启代理，不触发测速/healthcheck/订阅刷新。
- 原配置、副本、私有差异和导出记录留本机私有工作目录。生成文件可能包含节点凭据，请勿发到公开聊天。
- 本版未做商业签名／公证，不要求关闭系统安全策略。原生窗口可用性、真实客户端和真实设备网络分别验证。

## 开发与验证

开发使用 Python 3.12+（含 Tcl/Tk）和 PyYAML 6.0.3。构建依赖安装到任务虚拟环境，不改系统 Python。

```sh
python -m lite.app
python -m lite.app --config /path/to/synthetic.json --no-auto
python -m lite.app --self-test
python -m unittest discover -s tests -p 'test_lite_*.py' -v
python lite/build.py
```

`--no-auto` 禁止启动时发现真实客户端、读取本地控制接口或自动更新规则，供合成 UI 验证。`--self-test` 只在临时目录生成和核对合成链式配置、规则包解析，并加载 Tcl；不会启动窗口、联网或操作真实客户端。打包后重复该检查；Windows windowed 引擎用 `--result <新文件>` 输出记录。

Mac／Windows 分别原生构建，产物与大小、哈希及自检记录在 `lite/release/`。实际包体积以构建结果为准。旧版 Electron 桌面源码及交付包保留，不整树覆盖其他未完成界面改动。
